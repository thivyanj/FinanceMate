# 📱 FinanceMate - Personal Finance Tracker

**FinanceMate** is a Kotlin-based Android mobile application designed to help users manage their personal finances efficiently. The app allows users to track income, expenses, savings, and analyze their spending habits with ease.

## 🚀 Features

### ✅ Core Features
- **Transaction Management**
  - Add, edit, and delete income and expense transactions
  - Each transaction includes: title, amount, category, and date

- **Category-wise Spending Analysis**
  - Categorize transactions (e.g., Food, Transport, Bills, Entertainment, etc.)
  - View summarized expense reports per category

- **Monthly Budget Setup**
  - Set a monthly budget
  - Track real-time spending progress
  - Receive alerts when nearing or exceeding budget

- **Data Persistence**
  - Save preferences such as currency type and budget using `SharedPreferences`
  - Maintain transaction history across app restarts

### 🌟 Bonus Features
- **Data Backup & Restore**
  - Export transactions as a JSON or text file
  - Import and restore transaction data from backup

- **Push Notifications**
  - Alerts for approaching/exceeding monthly budget
  - Optional daily reminders to record expenses

## 🛠️ Tech Stack

- **Language**: Kotlin
- **UI**: XML Layouts (Android Studio)
- **Storage**: SharedPreferences & Internal Storage
- **Notifications**: Android Notification Manager
